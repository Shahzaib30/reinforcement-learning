# Reinforcement Learning Sandbox

A modular repository for implementing and benchmarking Reinforcement Learning (RL) algorithms. This project focuses on leveraging **Gymnasium** for environment interfaces and **Stable Baselines3** for robust agent training.

## 🚀 Features
- Custom Gymnasium environment integration.
- Training pipelines for PPO, DQN, and SAC.
- Visualizations via TensorBoard.
- Fast dependency management using `uv`.

## 🛠️ Installation & Setup

This project uses `uv` for extremely fast, reproducible Python environments.
